# Responsive Layout Project

This project is a simple responsive webpage built with HTML and CSS. It demonstrates the use of Flexbox and CSS Grid to create a clean, modern layout that adapts to different screen sizes.

## Features
- Responsive navigation bar
- Hero section with centered text
- Project gallery using CSS Grid
- Mobile-friendly layout adjustments via media queries
- Footer with navigation links

## Files
- `index.html` — page structure
- `styles.css` — layout and responsive styling

## Run the Project
You can view it directly by opening `index.html` in a browser.

For a local server, run:

```bash
python -m http.server 8000
```

Then open: http://localhost:8000

## Project Goal
The goal of this task is to practice creating a responsive web layout that works well on desktop, tablet, and mobile devices.
